# Git Commands Reference

## Setup & Config
### git config
Used to set user details
Example:
git config --global user.name "Aks Sun"

## Basic Workflow
### git init
Initializes a Git repository
Example:
git init

### git add
Stages files for commit
Example:
git add git-commands.md

### git commit
Saves staged changes
Example:
git commit -m "Initial commit"

## Viewing Changes
### git status
Shows working tree status
Example:
git status

### git log
Shows commit history
Example:
git log --oneline
