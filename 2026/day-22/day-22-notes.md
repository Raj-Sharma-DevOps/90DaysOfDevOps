# Day 22 Git Notes

## 1. Difference between git add and git commit
git add moves changes to staging area.
git commit permanently saves staged changes to repository.

## 2. What does the staging area do?
Staging area lets us review and select changes before committing.

## 3. What does git log show?
Commit history with commit ID, author, date, and message.

## 4. What is the .git folder?
It stores complete Git metadata and history.
Deleting it removes version control from the project.

## 5. Difference between working directory, staging area, repository
Working directory: actual files  
Staging area: selected changes  
Repository: committed history
