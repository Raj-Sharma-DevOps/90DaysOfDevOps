# Day 72 – Ansible Project: Docker and Nginx Deployment

# Project

Automated Docker + Nginx reverse proxy deployment using Ansible roles and playbooks.

```bash
ansible-playbook -i inventory/hosts.ini playbooks/deploy-docker-nginx.yml
```

---

# What Was Automated

1. Docker installation and service start
2. Nginx installation and reverse proxy config
3. Site enablement and handler-based reload
