# Day 61 – Introduction to Terraform

# Setup

```bash
terraform version
terraform init
terraform plan
terraform apply
terraform show
terraform destroy
```

Created first AWS EC2 instance with Terraform.

---

# Key Concepts

| Concept | Description |
|---|---|
| Provider | Plugin for cloud platform (aws, azure, gcp) |
| Resource | Infrastructure component to create |
| State | Terraform's record of what exists |
| Plan | Preview of changes before applying |

---

# Final Summary

Terraform provisions infrastructure declaratively. Write config, plan changes, apply — infrastructure as code.
